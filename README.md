# Bitrue Onboarding 周报

## 数据更新流程

1. 从后台导出两个 CSV 文件，放到项目根目录，文件名固定为：

```
注册漏斗-国家渠道-全部-1年.csv
注册漏斗-国家渠道-去羊毛-1年.csv
```

2. 运行：

```
./run.sh
```

3. 输出在 `output/` 目录：

- `weekly-report-{日期}.html` — 浏览器打开查看
- `weekly-report-{日期}.xlsx` — Excel 明细数据

## 报告内容

| 板块 | 说明 |
|------|------|
| 漏斗总览 | 注册→KYC1→KYC2→充值→交易，本周 vs 前4周周均值 |
| 人均金额 | 人均充值、人均交易，本周 vs 前4周 |
| 现货 vs 合约 | 交易金额占比 |
| 渠道排名 | 按交易金额排名，含排名变化 |
| 国家 Top 10 | 按注册量排名，含转化率和变化 |
| 羊毛分析 | 各渠道羊毛比例 |
| 月度趋势 | 月度注册量、转化率、金额趋势图 |

## 时间定义

- **本周**：数据中最新日期起往前 7 天
- **前4周均值**：本周之前的 28 天总量 ÷ 4
- **月度趋势**：全部数据的按月聚合

## 依赖

Python 3.9+，pandas / plotly / openpyxl（首次运行自动安装）
